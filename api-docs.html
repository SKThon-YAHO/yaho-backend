Users 5 endpoints
GET /api/users/me
Get user's information by local_code
Request
None
Response
200 { success: true, data: { local_code: string, num_toilet: string, role: string } }
404 LOCAL_CODE_NOT_FOUND
GET /api/users/dashboard
Get dashboard stats for manager's toilets (cleaning-needed badges)
Request
None
Response
200 { success: true, data: [{ toilet_code, name, locate, total_count, dirty_count, supply_count, needsCleaning }] }
GET /api/users/toilets
Get list of toilets managed by this local_code
Request
None
Response
200 { success: true, data: [{ toilet_code, name, locate, urinal_count, stall_count, status, last_cleaning }] }
GET /api/users/toilets/usage
Get visit count per toilet for a given period
Request
query { period: "day" | "week" | "month" } (기본값 day)
Response
200 { success: true, data: [{ toilet_code, name, visit_count }] }
POST /api/users/toilets/:toiletCode/cleaning

Request
body { cleaning_type: number }
Response
201 { success: true, data: { id, local_code, toilet_code, cleaning_type, created_at } }
403 NO_PERMISSION
Guest 2 endpoints
POST /api/guest/usage
화장실 이용량 카운트, 로컬 스토리지에 저장된 uuid가 없다면 쿼리 비워서 보내고, 반환된 uuid를 로컬스토리지에 저장 및 다음 요청 때 붙여서
Request
body { toilet_code: string, uuid: string(nullable) }
Response
200 { success: true, data: { uuid: string } }
400 MISSING_REQUIRED_FIELDS
POST /api/guest/survey
설문 라우트 survey는 아무것도 체크 안 함 -> 0, 청결도만 체크 -> 1, 비품만 체크 -> 2, 전부 체크 -> 3 으로 세팅
Request
body { toilet_code: string, survey: int, uuid: string }
Response
200 { success: true }
400 MISSING_REQUIRED_FIELDS
